# Jasper P 个人展厅 — 第一阶段设计稿

第一阶段交付首页、联合发券案例、研究与学术的三张桌面（1440×900）和三张手机（390×844）首屏画稿，以及四个转场关键帧。视觉确认后再制作五个主题模块和完整网站。

## 开发与构建

在本目录执行：

```sh
npm ci
npm run build
```

构建产物写入仓库 `design/`，设计预览地址为 `/jasper-resume/design/`。完整交互版 `about/` 尚未创建。

- 默认画布支持桌面／手机／转场切换、移动缩放、全屏查看、左右键切页和 Esc 返回。
- `?screen=home-desktop` 等导出参数直接渲染原始画稿，供截图使用；它们是设计画稿，不是完整网站页面。
- 画布使用高清截图，避免浏览器在大比例 SVG 缩放时出现文字光栅问题。原始 React/SVG 组件保留，供第二阶段复用。
- UI 中的导航、联系与项目按钮是设计展示，完整路由与业务交互在第二阶段接入。

## 素材与事实来源

内容依据当前定稿简历；联合发券日均净收贡献表示增至约 6.2 倍（2026.06–09），不表示增长 6.2 倍。130 次被引对应单篇代表作，4 篇为已发表论文总数。几何图形与机制图均为原创示意。

字体 Archivo 来自 Google Fonts，OFL 许可随字体保存。设计画布复用 lark-apps creative-design starter，存储适配为浏览器本地布局，不上传用户信息。

`frozen-files.json` 记录原一页简历 HTML/PDF 和既有入口的校验值，构建与发布需验证这些文件未变。

## 第一阶段第二轮修订

按用户反馈强化内页差异：项目案例采用全宽阶段结果带与横向协作链，研究页采用教育／论文／分析实践的纵向阅读轴与文献卡。手机按相同信息结构适配，分镜落地画面同步为新版项目页。首页、原一页简历及其 PDF 均保持不变。
